# JPlag Electron app (TypeScript + Electron Forge)

1. Copy your `jplag.jar` into `resources/` (delete the placeholder .txt).
2. Open `src/main.ts` and fill in `JPLAG_ARGS` with your JPlag arguments.
3. `npm install`
4. `npm start` (dev) or `npm run make` (installer)

Java must be installed on the machine running the app.
